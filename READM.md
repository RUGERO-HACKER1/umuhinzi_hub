# UmuhinziHub - AI-Powered Agritech Telemetry Dashboard

An open-source mobile and web orchestration framework built to optimize agricultural productivity for smallholder farmers and cooperatives across Rwanda. 

## 📊 Data Use & National Priority Alignment
This project aligns directly with Rwanda's **National Strategy for Transformation (NST2)** and **Vision 2050** priorities regarding food security, climate resilience, and modernized agricultural frameworks. 

The application architecture processes and acts upon microdata layers from the **National Institute of Statistics of Rwanda (NISR)**, specifically integrating structural trends from the **Agricultural Household Survey**.

### Data Sources
* **Primary Microdata:** NISR Central Data Catalog — [Agricultural Household Survey Metrics](https://statistics.gov.rw)
* **Real-time Ingest:** Synthesized local soil moisture thresholds, temperature indicators, and environmental telemetry constants.

## 🛠️ Technology Stack
* **Frontend Mobile Client:** React Native (Expo) featuring a fully mobile-friendly, offline-first UI layout.
* **State Management & Hooks:** Isolated asynchronous client-side context hooks.
* **Component Architecture:** Reusable native dashboard layers for crop cycle prediction modeling.

## 🚀 How to Run the Project Locally
Ensure you have Node.js installed on your machine.

1. Clone the public repository:
   ```bash
   git clone https://github.com/RUGERO-HACKER1/umuhinzi_hub.git
   ```
2. Navigate into the project folder and install dependencies:
   ```bash
   cd umuhinzi_hub
   npm install
   ```
3. Boot up the local development server:
   ```bash
   npx expo start
   ```
